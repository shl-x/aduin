# Panduan per peran

{% tabs %}
{% tab title="Warga" %}
1. Buka **Lapor dan aduan saya** (`/lapor`).
2. Tulis keluhan di kolom chat. Pilih desa dan lampirkan foto kalau ada.
3. Jawab pertanyaan bot kalau laporan masih kurang lengkap.
4. Pantau status di kolom **Aduan saya**.
5. Setelah petugas selesai, pilih **Ya, sudah beres** atau **Belum beres**.
{% endtab %}

{% tab title="Operator" %}
1. Buka **Antrian kerja** (`/dashboard`) dan mulai dari tahap **Perlu dicek manusia**.
2. Buka detail aduan. Baca **Keputusan AI** dan alasannya, lalu koreksi kalau perlu.
3. Untuk masalah lintas dinas, klik **Buat Rencana Koordinasi**.
4. Tinjau foto bukti yang diragukan AI: setujui atau kembalikan dengan catatan.
5. Pantau **Peta** dan **Peringatan** untuk melihat pola dan lonjakan.
{% endtab %}

{% tab title="Petugas OPD" %}
1. Buka **Tugas saya** (`/tugas`).
2. Klik **Mulai Kerjakan** pada tugas yang belum mulai.
3. Klik **Tandai Selesai** setelah pekerjaan beres.
4. Setelah semua tugas aduan selesai, unggah foto lewat **Unggah Bukti Penyelesaian**.
{% endtab %}

{% tab title="Pimpinan" %}
1. Buka **Ringkasan kinerja** (`/ringkasan`).
2. Pilih rentang grafik 7, 30, atau 90 hari.
3. Lihat kecamatan dengan aduan terbanyak dan dinas yang perlu didorong.
{% endtab %}
{% endtabs %}
