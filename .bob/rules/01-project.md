# Ringkasan Proyek Aduin

- Aduin adalah otak analitik di balik kanal pengaduan masyarakat pemerintah daerah, dibuat untuk hackathon IBM.
- Kanal existing (contoh: hotline WhatsApp Halo Sae di Kab. Probolinggo) hanya menerima dan meneruskan aduan. Aduin menambahkan analisis, koordinasi lintas OPD, verifikasi penyelesaian, dan peringatan dini.
- Pengguna: warga pelapor, operator command center, petugas OPD, pimpinan daerah.

## Scope MVP (hanya ini yang dibangun)
1. Simulator WhatsApp + data seed sebagai intake aduan
2. Triage AI explainable (kategori, OPD, urgensi, dampak, jalur, alasan)
3. Clustering aduan + peta hotspot
4. AI agent koordinasi lintas OPD
5. Verifikasi penyelesaian dengan foto sebelum/sesudah
6. Early warning lonjakan aduan
